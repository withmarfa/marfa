**Use for**

- Something to do.

**Not for**

- Notes about the work. Those are a `core.note`. Name that note from the task with `about` when the task is about it.

**Body**

- `title` is what needs doing. `status` is `not_started`, `in_progress`, `completed`, or `canceled`. `due_at` is when it is due.

**Edges**

- `about` runs from this task to the item the work is about.
