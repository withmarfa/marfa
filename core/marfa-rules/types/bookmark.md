**Use for**

- A web address to come back to.

**Not for**

- A copy of the page. Saved HTML is a `core.file.webpage`. The article's own text is a `core.media.article`.
- A passage highlighted in an item you already keep. That is a `core.highlight`, linked to the item with `excerpt-of`. A passage clipped with its web address belongs in this bookmark's `body`.

**Body**

- `url` is the address. `title` is the page title. `body` is text you captured from it, such as a clipped paragraph. `notes` holds your own comments.

**Edges**

- `in-collection` runs from this bookmark to a `core.collection`, such as a reading list.
