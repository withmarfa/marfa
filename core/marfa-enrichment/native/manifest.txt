# Every source the native build uses, pinned. The scripts in this folder and
# build.rs read it; nothing else says what is built.
#
# Each line is whitespace-separated fields. A line starting with # is a comment.
#
#   archive <name> <version> <url> <sha256>      a source archive, verified before it is unpacked
#   model   <language> <url> <sha256>            a tessdata_fast model, carried inside the program
#   git     <name> <url> <ref> <commit>          a git checkout that must resolve to exactly <commit>
#   tool    <name> <url> <sha256>                a build tool fetched as an archive
#   image   <name> <reference>                   a container image, by digest
#   apt-snapshot <name> <timestamp>              the date of the Ubuntu package archive the image installs from
#   toolchain <name> <version>                   a compiler version the builder must have
#   kernel  <name> <url> <sha256>               a Linux kernel package that native/vm.sh boots to run the x86_64 program
#   licence <name> <url> <sha256>                a licence text that ships with a program and that no source archive holds
#
# To move a pin, change the URL and the hash together: the build stops at the
# first hash that does not match.
