# The tunnel connector every release ships beside `marfa` and `marfa-server`:
# one version of cloudflare/cloudflared, taken from its official GitHub release,
# with the SHA-256 of each download. `fetch-cloudflared.sh` reads it and stops at
# the first hash that does not match, so a release cannot carry a connector this
# file does not name.
#
# Each line is whitespace-separated fields. A line starting with # is a comment.
#
#   version <tag>                                the cloudflared release, which is also its git tag
#   licence <sha256>                             the LICENSE file at that tag
#   team <id>                                    the Apple team that signs the macOS program
#   download <target> <asset> <download sha256> <program sha256>
#                                                the release asset for a build target, and the
#                                                program inside it; a plain download is its own program
#
# To move the pin, read the release page, then change the version and every
# hash together. Cloudflare's page lists the macOS programs' hashes, not their
# archives', so take the download hash from the file you fetched (GitHub shows it
# as the asset's digest) and the program hash from the page.
#
# Cloudflare stops publishing Intel macOS builds in 2027, and Marfa builds none.
